monkey_dust

Open-world isometric RPG sandbox for Linux. Isometric tile rendering pipeline inspired by Flare Engine. Solo project built with SDL3 + SDL_GPU (Vulkan) + EnTT + Recast/Detour.

Target hardware: Intel HD 520 (Skylake AVX2) · Vulkan via SDL_GPU · 4–8 GB shared RAM · 1280×720 · 60 FPS

Build

git clone --recurse-submodules https://github.com/rdga1bot/monkey_dust.git
cd monkey_dust

# Primary build (SDL3 + SDL_GPU — only supported path):
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DUSE_SDL3=ON
ninja -C build monkey_dust           # game        → build/game/monkey_dust
ninja -C build monkey_dust_editor    # editor      → build/tools/monkey_dust_editor
ninja -C build md_flare_convert      # converter   → build/tools/md_flare_convert
ninja -C build md_flare_demo         # map viewer  → build/tools/md_flare_demo

# Test suite:
ninja -C build md_tests && build/tests/md_tests

-DUSE_SDL3=ON is the only actively developed and supported path. It automatically sets MD_SDL_GPU as the exclusive rendering backend, enables GLM math, and excludes Raylib from the build entirely. The old -DUSE_SDL3=OFF (Raylib+GLFW) path is kept for reference only and is not maintained.

Debug build (ImGui overlay, WorldPlacer, TimingSystem):

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug -DUSE_SDL3=ON
ninja -C build monkey_dust

Wicked-style in-game editor (Phase 34):

cmake -S . -B build -G Ninja -DUSE_SDL3=ON -DMONKEY_DUST_EDITOR=ON
ninja -C build monkey_dust

Recompile SPIR-V shaders after any .vert/.frag/.comp change:

bash scripts/compile_shaders.sh

Shader hot-reload (no restart required):

# Terminal 2: watch + auto-recompile on save
bash tools/shader_watch.sh
# In editor console:
/reload-shaders

GPU debugging with RenderDoc:

SDL_GPU_DEBUGMODE=1 renderdoc build/tools/monkey_dust_editor

Technical constraints

  • No malloc/free/new[] in hot path — fixed arrays + EnTT pools
  • No std::vector/map in hot path — fixed arrays [MAX_N]
  • No external JSON libraries — custom strstr parser throughout
  • No C++20 — C++17 maximum
  • No FSM for AI — BehaviorTree.h only
  • No assert() — MD_LOG_WARNING + return default
  • No mutation of registry during view.each() — collect → apply
  • All ImGui/editor code behind #ifdef MONKEY_DUST_EDITOR
  • SDL_GPU exclusive: MD_SDL_GPU always defined when USE_SDL3=ON; no raw GL calls outside HAL impl files
  • Engine split-readiness: engine/ has zero #include from game/ or tools/
  • Math: engine/ never includes Raylib headers; Vec3/Mat4 via <monkey_dust/math_types.h>
  • Lua sandbox: 8 MB memory hard cap via custom lua_newstate allocator; io/os/package/debug + dofile/loadfile/load nil-ed after luaL_openlibs; 10 000-instruction hook

Intel HD 520 — Hardware Checklist (ПЕРЕВІРЯТИ ПЕРЕД КОЖНИМ GPU PR)

□ Push constants: vert ≤ 128B, frag ≤ 128B. Разом VU(64B)+HairFU(16B)+HairShadingFU(80B) < 256B OK.
  НЕБЕЗПЕЧНО: два mat4 (128B) в одному vert UB — може overflow на деяких конфігах.
□ frag_uniform_bufs МУСИТЬ = кількості set=3 binding=N у SPIR-V шейдері.
  Порушення → silent garbage у binding N+1 → NaN → white fragments.
□ Depth format: ТІЛЬКИ D32_FLOAT. D24_UNORM = GPU hang на Intel Gen9 (ANV driver).
□ frag_samplers + vert_storage_bufs > 0 = silent fail (SDL3 3.4.8 bug). Workaround: vert SSBO→location=4.
□ vert_samplers > 0 + frag_samplers > 0 = GPU hang → повний freeze ОС на Intel Gen9 ANV.
  Workaround: vertex height reads через VBO (pre-computed CPU side), НЕ через vertex texture sampling.
□ OIT composite: ТІЛЬКИ compute path. Fragment path з 2+ samplers = crash.
□ Z-fighting hair/skin: depth bias у vert shader: gl_Position.z -= 0.0003 * gl_Position.w.
  Більше 0.001 → hair перекриває обличчя. Менше 0.0001 → Z-fighting повертається.
□ Skirt geometry: тільки LOD=0 (ground-level). Для LOD1+ — непотрібно і подвоює draw calls.
□ LOD alt_scale: масштабувати alt_scale ТІЛЬКИ для culling distance (d3sq).
  НЕ масштабувати LOD пороги (d0/d1/d2sq) — інакше bird's-eye = 1-5 FPS (всі чанки → LOD0).
